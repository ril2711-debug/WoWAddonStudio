# WoW Addon Studio v0.5.0 — Function Explorer & Hotspots

## Recursos

- Scanner e Risk Explorer
- Tabela de símbolos
- Funções chamadas e chamadoras
- Fan-in e fan-out
- Profundidade de chamadas
- Acoplamento entre arquivos
- Manutenibilidade
- Ranking de hotspots
- CallGraph.dot
- DependencyGraph.dot

## Uso

Execute `INICIAR_WAS.bat`, informe a pasta do addon e abra
`reports/AuditReport.html`.
